# Official assets

Nothing in this folder is generated. Every file here is supplied and approved by
Billawar Association Mumbai and is used on posters **exactly as supplied**.

```
association/       Registered association logo
guru/              Approved image of Brahma Shree Narayana Guru
koti-chennaya/     Approved image of Koti-Chennaya
temples/           Approved temple photographs
decorations/       Approved decorative artwork (borders, dividers, motifs)
offices/<office>/  Per-office branding
```

The folders ship empty. See [`docs/ASSET_REPLACEMENT.md`](../../docs/ASSET_REPLACEMENT.md)
for how to install the real files and register them in `manifest.ts`.

An asset placed here is never recoloured, stretched, mirrored, cropped outside
the approved shapes, stylised, background-removed, AI-enhanced or AI-regenerated.
